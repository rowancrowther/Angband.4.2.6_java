# Precis — 2026-10-01

## Key points from the day

### `CriticalLevel` retired in favour of `MeleeCriticalLevelData`

`CriticalLevel` was the Java form of `struct critical_level` in `init.h`, but nothing constructed it, because the parsed
tables were already held as `MeleeCriticalLevelData` and `RangedCriticalLevelData` records. Rowan deleted the class, so
the records are now the only Java form of that struct, and `O_CriticalLevel`'s Javadoc points at the melee record
instead. `MeleeCriticalLevelDataTest` loads the shipped `constants.txt` and pins every melee and ranged row. The future
`critical_melee` and `critical_shot` ports can read the lists on `GameConstantsData` directly, and still need
`check_critical_levels` ported alongside them.

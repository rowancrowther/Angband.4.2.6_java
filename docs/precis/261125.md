## Key points from the day

### Activation

`Activation` is the Java form of C's `struct activation`, the record `activation.txt` fills through the `parse_act_*` handlers in `obj-init.c`. Its field and method blocks were one-line stubs, so nothing said which C member each field stood for, that `aim` is parsed but never read by C, or that `copy()` throws on a null effect list. The class, all seven fields, the constructor and the accessors now carry full Javadoc naming the C member, its parse handler and its readers, and `ActivationCopyTest` now pins effect order, the null message and description, the caller's list being kept, and the null-list throw. Later code that reads an activation's level, message or description has the C readers to port against, and a null effect list is documented as unsupported rather than found out at runtime.

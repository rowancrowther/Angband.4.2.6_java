# Precis — 2026-10-23

## Key points from the day

### Artifact.copy

`Artifact.copy` is the port of C's `copy_artifact` in `obj-randart.c`, which copies the whole struct, gives the copy its own brand, slay and curse arrays, and sets the copy's `activation` and `alt_msg` to `NULL`. The Java copy had carried the activation and message across, and threw on a `null` curse map where C keeps a `NULL` curse array as `NULL`, though the class itself treats `null` as valid. `copy` now leaves the activation and message `null` and copies a `null` curse map as `null`. Four copy tests that expected the activation to be carried across were rewritten to C's behaviour, `ArtifactCopyCursesTest` covers the null, empty and populated curse maps, and the full suite is green.

# Precis — 2026-11-17

## Key points from the day

### BlowEffect2Assembler

`BlowEffect2Assembler` turns the ordered `BlowEffect2ParseRecord`s of `blow_effects.txt` into `BlowEffect`s; it is the Java form of the `parse_eff_*` handlers in `mon-init.c`. Its ten value-count guards built their message with `substring(0, length - 2)`, so a directive with no values threw `StringIndexOutOfBoundsException` where C refuses a missing field, and the class and its thirteen methods had no Javadoc. The guards now skip the trim when nothing was appended, and the class and every method carry full Javadoc naming the C handler, the accepted deviations and the dependency on the loaded projections. `BlowEffect2AssemblerTest` pins the refusal for all ten directives, the name-first rule, the three colour targets and the hand-built record shapes that the reader tests cannot reach. Later readers that hand-build `Directive`s can rely on a bad value count being refused with the line quoted.
